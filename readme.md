# 🌱 Maza Gaon

## Digital Village Community Platform

Maza Gaon is a CEP project designed to create a digital platform
for rural communities.

The website brings important village services together in one place.

## Main Modules

- 🌾 Agriculture
- 🏥 Healthcare
- 📚 Education
- 🧼 Hygiene and Sanitation
- 💧 Water and Electricity
- 📝 Community Complaint System
- 🏛️ Government Schemes
- 📢 Village Information

## Languages

The platform is designed to support:

- English
- Marathi
- Hindi

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Objective

To provide a simple digital platform that helps villagers
access useful information and communicate local problems.
